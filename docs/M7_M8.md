# M7–M8 离线验证与去毛刺路径预览

本扩展接续现有 M1–M6 产物，不修改配准矩阵，不包含 M9 机器人控制。
用户的 0.2 mm／1 mm 是配准精度目标，与毛刺阈值、去除深度分开记录。

## M7

执行已知几何符号/量值验证，回查保存的法向与欧氏距离，并对原始 STEP 的
B-rep 曲面进行分层抽查。检查只证明数值计算与几何表示的一致性，不代替
实物材料侧、独立配准精度和工艺公差验证。

```bash
.venv/bin/python -m pip install -r requirements-planning.txt
.venv/bin/python 06_validate_m7.py --run-dir output/m7_m8/my_run
```

参数默认来自 `planning.example.json`。需要改动时复制到忽略的
`planning.local.json`，并使用 `--planning-config planning.local.json`。
每次使用新的 run-dir，保留先前实验。

M7 实际结果、输入哈希、代码版本与脏工作区状态写入该目录。网格与 STEP
抽查阈值是几何表示检查门槛，不能成为扫描/配准精度的认证。

## 使用的外部库

- [OpenCAMLib](https://github.com/aewallin/opencamlib)：本扩展直接调用
  `BatchDropCutter` / `BallCutter` 计算三角网格的球形工具接触位置。
  [官方算法说明](https://opencamlib.readthedocs.io/en/latest/)说明 drop-cutter
  会沿固定方向移动工具，直到接触模型。固定版本 2023.1.11，LGPL-2.1。
- [Shapely](https://github.com/shapely/shapely)：直接用于区域并集和孔洞保留的
  线段裁剪，固定版本 2.1.2，BSD-3-Clause（底层 GEOS 另遵循其许可证）。
- [Noether](https://github.com/ros-industrial/noether)：考察了其曲面和边界路径
  实现；需要 PCL/VTK 等 C++ 构建依赖，本次未安装或声称调用它。
- [arm_coverage](https://github.com/uwgraphics/arm_coverage)：研究性机械臂覆盖
  排序参考，不能直接从偏差场识别毛刺。当前无实际机器人模型，未接入。
- [Tesseract](https://github.com/tesseract-robotics/tesseract) / [OMPL](https://github.com/ompl/ompl)：
  为后续 M9 的运动规划候选，本次未使用。

仓库活跃度、工业背景和可运行性用于选型，没有把 GitHub stars 说成论文引用数，
也没有声称查询到可核实的引用排名。第三方库通过依赖安装，没有复制源码。
本项目原创适配代码保持 MIT；第三方组件遵循各自许可证。

## M8 与查看路径

```bash
.venv/bin/python 07_generate_m8.py --run-dir output/m7_m8/my_run
```

M8 读取同一 run-dir 中 M7 的配置与输入哈希；输入或配置改变则需建立新运行。
结果写入 `m8/`：`target_pose.csv`、`candidate_regions.csv`、离线 HTML、PNG、
参数/验证清单与中文报告。默认参数为从 CAD -Z 侧接近、直径 4 mm 球形工具，
仅作预览假设。没有把 1 mm 配准目标用作磨削深度。

路径先按当前质量掩码、局部突出量、空间与法向连续性构造候选区，再将裁剪的
往复线交给 OpenCAMLib。只保留与原候选区对应的球头接触段；在采样点及中点
检查球体到 CAD 的间隙，并加入独立的抬刀/转场。检查不等于连续碰撞认证。

CSV 的 XYZ 是 CAD 坐标系下的球心位置；四元数顺序为 XYZW，工具 +Z 指向
工件。`nominal_contact` 是名义 CAD 包络，不代表已经决定实际加工深度。
去除量、速度、接触力留空，`execution_allowed=False`。这不是机器人程序，
也不包含毛刺真值、磨头杆/夹具碰撞、机器人 IK 或力控制。

## 一键运行与验证范围

```bash
./run_m7_m8.sh output/m7_m8/my_new_run planning.example.json
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 .venv/bin/python -m pytest -q tests
```

狭长区域沿平面主方向排列往复线，减少短接触段。每一接触边都检查其仍在
候选支持范围内；另一层表面遮挡的区域不会投射成错误接触点。
球体间隙的默认容差为 0.02 mm，包含离散采样和弦线近似，不能声称严格无穿入。
实际工具、连续路径与夹具碰撞仍待后续验证。区域内未靠近路径的候选保存在
`candidate_path_coverage.csv`，不会因为未生成路径就被判定为无毛刺。

基础环境没有安装可选规划依赖时，规划测试会明确 skip；完整 M7–M8 验证应先
安装 `requirements-planning.txt`。当前合成测试还检查了遮挡层、孔洞、局部凸起
与整体偏移的区分，以及四元数、坐标、路径步长和非执行状态。
